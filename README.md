One word, and nothing else: the single word grandma would text about AI.

**The word: `newfangled`**

It is the word grandmothers actually use for new technology — "that newfangled thing" — warm, a little baffled, and funny in one word with no caption needed. Studied against all 212 existing submissions before choosing: the field is dominated by robot typos (`robit`/`robut`), gadget nouns (`doohickey`, `contraption`, `thingamajig`) and magic words (`witchcraft`, `voodoo`); `newfangled` appears nowhere in it, and it is a fresh angle — an adjective describing the thing, not another name for a robot.

## Run it

```sh
node main.ts
```

Writes the word to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to use another directory). Deterministic, standard library only, Node 22.
